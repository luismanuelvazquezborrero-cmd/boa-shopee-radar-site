Política de Privacidade — Radar de Pins BOA SHOPEE

Última atualização: 16 de outubro de 2026

Esta política explica como o Radar de Pins BOA SHOPEE trata os dados quando o titular da conta conecta sua própria conta do Pinterest à ferramenta para uso pessoal.

Quem opera a ferramenta

A ferramenta é operada pelo titular da conta de desenvolvedor BOA SHOPEE, para uso individual.

Dados acessados

Com a autorização do titular via Pinterest OAuth, a ferramenta poderá acessar os dados da própria conta autenticada que forem necessários para a função solicitada, como identificador e informações básicas da conta, Pins e quadros próprios, metadados e métricas que a API do Pinterest disponibilizar.

A ferramenta não solicita acesso aos Pins ou quadros de outras pessoas, não busca dados de contas alheias e não coleta dados de vendas. Métricas de engajamento não são uma confirmação de compras.

Como os dados são usados e armazenados

Os dados são usados somente para mostrar e organizar relatórios pessoais sobre o conteúdo da conta Pinterest conectada. A ferramenta foi projetada para ser executada no computador do titular. Os tokens OAuth e os dados obtidos pela API ficam armazenados localmente nesse computador e não são enviados a outros serviços pelo operador. As chamadas de API são feitas diretamente ao Pinterest e estão sujeitas às políticas e aos termos do Pinterest.

Compartilhamento e retenção

O operador não vende, aluga ou compartilha esses dados com terceiros. Os dados locais permanecem no computador até que o titular os remova. O titular pode revogar o acesso da ferramenta nas configurações da conta Pinterest; a revogação impede novas chamadas autorizadas à API.

Segurança

O titular deve manter seu computador protegido e não compartilhar tokens, arquivos de configuração ou cópias locais da base de dados. Nenhum sistema pode garantir segurança absoluta.

Alterações

Esta política será atualizada se a ferramenta passar a coletar, armazenar ou compartilhar dados de outra forma. O titular pode revogar o acesso da aplicação nas configurações da conta Pinterest e remover os dados locais da ferramenta do próprio computador.
